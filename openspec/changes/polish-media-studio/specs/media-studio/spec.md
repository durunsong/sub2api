# 验收标准

1. 桌面图片工作台不显示重复“生图工作台”标题，Tab、说明、操作处于同一 toolbar；移动端不横向溢出。
2. 生成只发一次 generate；提交到轮询 active 不出现空档；多个进度更新不改变用户滚动位置；同一 composer 不重挂载；错误/暂停不出现巨大空白。
3. 参数按钮打开浮层后，点文本框、页面空白或切换 Tab 均关闭；点击浮层内控件保持打开；Escape 返回焦点。
4. 默认精选提示词；七类来源与 upstream 一致，搜索/分类/标签组合有效，卡片和详情一键使用精确回填，绝不自动提交。
5. 自定义提示词、原有图片 AI 工作流/变量/系列执行不变；断网保留缓存，自定义仍可访问；源请求不发送面板凭据。
6. 浅色/深色、桌面/移动端、管理员 Tab 截图验收；相关自动化回归、类型、lint、构建通过；UTF-8 无 BOM/异常字符。
