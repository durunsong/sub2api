# 实现决定

- 顶部：图片/视频 Tab、现有本地存储说明、原有按钮并排，宽屏一行，窄屏自然换行。删除二级重复标题，管理员沿用共享 Tab。
- 状态：提交保存 taskID 后连续交接轮询控制器；最终刷新状态后才释放运行标记；异步 refresh 序号拒绝旧读取覆盖新状态。分别监听 sessionID 和记录数量，进度变化不滚动。底部 composer 在正常 flex 布局中保持同一实例。
- 结果：统一左对齐的提示词、元信息与结果卡，运行/暂停/失败占据同一尺寸状态区，去掉巨大标题与虚线占位。只改变展示。
- 弹层：捕获阶段处理 pointerdown，只排除触发器与浮层自身；切换工作台时关闭；Escape 关闭并返回焦点。
- 提示词：参考 infinite-canvas 4c67f1e 的 prompt-source-presets/runtime/prompts 和 prompt-select-dialog；七个公开 JSON 来源与上游一致。标准 fetch 不带 JWT/cookie；HTTPS URL 校验；不用远程脚本或 HTML 注入。按来源缓存一小时，失败回退缓存并显示来源/重试。图片懒加载、分页显示，每次40条；来源顺序固定，分类和关键词组合，多标签 OR。
- 共享 PromptLibraryDialog 给图片和视频使用；自定义通过插槽保留现有工作流/保存删除代码。一键使用仅回填文本，不改模型/参数，不自动生成。公开参考图不自动加入用户请求。
- OpenSpec CLI 在本环境未配置，使用已有仓库文档结构记录，不声称执行过 CLI 验证。
