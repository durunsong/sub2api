# 订阅重置记录

## 目标与范围
管理端 `/admin/subscriptions` 和用户端 `/subscriptions` 按订阅查看用户重置卡消费及管理员单条/批量重置的分页记录。用户已确认该范围，普通用户只能查询自己的订阅。

## 非目标
不记录自动日/周/月窗口滚动；不改变重置卡期限、扣卡幂等、配额或支付规则；不操作生产或执行生产迁移，不纳入原有三个兑换文件的改动。

## 验收
旧消费记录可读；单条/批量管理员重置与记录原子写入；失败回滚不留成功记录；普通用户越权和无认证请求被拒绝；分页稳定且没有凭据/订单引用泄露；两端入口、空态、失败重试及请求竞态有回归。通过测试、构建、静态检查和独立审查后提交并 push。
