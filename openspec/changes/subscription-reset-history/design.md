# 设计

## 数据来源
直接查询既有 `user_subscription_reset_cards.consumed_at`（包括已消费后退款的卡，保留事实），不复制、不回填、不改变消费 SQL。新增 `251_subscription_quota_reset_history.sql` 保存管理员重置时间和日/周/月范围。现有仓储 `ResetUsageWindows` 用单个 PostgreSQL CTE 将用量清零和记录插入原子完成；保持日窗口午夜和周/月点击时刻的锚点。批量操作复用该入口及原有逐项事务。只记录成功变更，不新增金额字段或改变精度。

## 查询与权限
两类记录 UNION ALL 后按发生时间、类型及来源 ID 倒序，固定上限分页；不公开来源引用、幂等键、操作者邮箱等。用户 API 在服务端检查所有权，隐藏不存在/他人订阅；管理 API 沿用管理员授权，允许查看已撤销订阅。记录展示时间、重置方式、重置范围与卡期限。旧管理员重置没有可靠的专用历史，不伪造回填；界面明确说明该覆盖边界。

## 界面
复用 BaseDialog、Pagination、现有按钮/颜色，新增共享记录弹窗；打开或切换订阅从第一页加载，关闭/翻页取消旧请求并防止旧响应覆盖。中英双语，保留用户端 Claude 品牌别名。当前无已确认的新视觉设计需求，不做页面重构。

## 迁移与回滚
只交付新的 SQL，历史迁移不改；真实验证仅在测试容器进行。部署需先备份并应用新增表/索引，应用回滚可保留新增表；旧版本运行期间的管理员重置无法留痕，已有记录不删除。重置及记录失败由同一语句/事务回滚，无额外补偿任务。
