# Design

## 依据与边界
参考 https://github.com/tigerowo/infinite-canvas ，调查版本 dc1f1d7e741eaae24c7c11a8de8892f36ed01b49。仅生图工作台为范围。站点既有 AppLayout、Select、ConfirmDialog、i18n 和主题为视觉权威；布局与工作流遵循参考项目。

## 架构
1. 后端工作台目录与管理员配置复用 settings 存储，分组和模型来源复用 Gateway/APIKey 服务。目录授权与提交时授权同源，模型能力显式表达，不把任意文本模型猜成生图模型。
2. JWT 认证的工作台接入既有同步图片/兼容网关，使用真实 APIKey 账务身份：每用户/分组以 JWT secret HMAC 派生 `internal:images:` 凭据，数据库唯一约束处理并发创建。外部认证、常规密钥管理、计数和 DTO 回显排除该身份。服务器每次提交重验分组授权，再通过仅进程内可设置的上下文传递凭据；固定路径转入同一网关路由链，无 HTTP 回环、虚拟账务 ID 或新增迁移。
3. 前端独立 imageStudio API/types、IndexedDB 仓储、工作台状态与页面组件。数据库以用户 ID 命名，每条成功记录包含真实 Blob 和生成参数；分类/素材仍只在同一数据库。
4. 不采用服务端异步/批量任务，不把创作内容写入审计或 Ops。仅目录配置、既有凭据与账务元数据持久化服务端。

## 资金与失败边界
价格币种、精度与事务全部继承现有网关。无需新资金迁移。生成不自动重试；用户主动重试提示可能再次计费。取消仅终止请求，已发生上游用量按已有语义结算。前端价格取服务端信息，不用浮点计算结果作为账务依据。

## 存储与恢复
IndexedDB 同一事务保存 Blob/参数并删除对应任务，枚举时过滤无有效 Blob 的项。刷新/聚焦/跨标签变更重新读取；删除先提交事务再更新视图。关闭/卸载取消当前客户端任务，刷新不重放。存储失败保留会话结果供下载，明确未保存，不混入历史。所有 Blob URL 释放。

每个工作台实例通过原生 Web Locks 持有账号作用域的 owner 锁，任务记录保存 ownerID；其他标签页只提示活跃任务，不把它们改为中断或提供重复重试。owner 消失后刷新才恢复中断状态；完成和删除通过 BroadcastChannel 同步。Web Locks 不可用时仅在当前视图提示“未追踪，可能仍在其他标签页/上游执行”，不改写共享运行状态，人工重试仍需确认可能再次计费。

## 安全
目录不返回上游凭据；JWT 身份与分组授权在服务器复核。限制提示词、参考图片 MIME/数量/大小、模型和参数；参数仅允许声明值。操作使用当前请求上下文，不循环调用任意外部 URL。

`NoContentPersistence` 标记沿同步网关及异步安全元数据工作传播。保留安全判定/封禁/余额与配额控制；不排入含内容的审计任务、不捕获 Ops 请求或响应、错误写日志/账号字段前移除上游回显。Grok/Images URL 仅由既有 SSRF 防护抓取内联化，浏览器不接收上游 URL。记录模型、费用、数量、用量和请求 ID 等必要账务元数据。

## 参考功能映射
沿用参考工作台的两种布局、参考图上传/粘贴/拖拽、1–10 张独立任务、失败重试、历史多分类与多选下载删除、素材、模板变量/系列和蓝色标记局部编辑。模板及工作流改为纯本地数据；不接参考站点云库、云同步或个人 API 配置。独立无限画布、视频和导演台不属于本次生图工作台。GPT Image 2 自定义尺寸使用 16 倍数、单边不超过 3840、比例不超过 3:1、面积 655360–8294400 的参数约束；具体模型能力由服务端目录声明。

## 验证
后端目录过滤/权限/配置校验/网关路由/隐私/计费接线测试；前端状态、API、存储及组件测试；真实浏览器验证 IndexedDB 清理、账号隔离、任务并发、图生图、导出/导入、桌面与移动深浅色。运行 Go build/vet 和相关测试、pnpm vitest/typecheck/build/lint，记录真实结果。

## AI 工作流补齐（2026-11-17）

选择复用进程内同步文本网关，而非新增供应商客户端或要求用户配置文本API。自动发现已授权文本模型，复用现有分组授权、模型显示覆盖、账务与NoContentPersistence。模型可来自独立的文本分组，不要求该分组开启生图。新增独立文本模型目录与workflow接口，具体契约见tasks 11；不更改原图片生成请求契约。

前端扩展现有WorkflowLibrary：AI需求→模型/参考图→可编辑模板→明确保存到本地；系列生成→1–20条完整提示词→编辑审核→明确生图。手工创建与系列仍保留。文本和图片请求都可能计费，展示准确提示，不自动执行、不重放；取消/关闭/账号切换中止请求且丢弃迟到结果。生成的工作流数据继续使用本地ImagePrompt结构，避免无必要的数据库升级。

验收：真实HTTP fixture验证文本生成、参考图、编辑保存、刷新恢复、系列审核和单次明确生图；无权限/无文本模型/隐藏/失败/取消可恢复，手机和桌面可操作；后端验证所有输入/输出限制及原网关账务身份、内容不落日志，不将fixture验证宣称为真实供应商结算。


## 低高度操作与生成动效补充（2026-11-17）

本次范围为配置流程文档、生成入口可达性与等待反馈；复用现有提交、队列、计费和 IndexedDB，不修改网关或生产配置。原生成按钮被视口/内部滚动裁切时显示底部操作条，包含当前模型、张数与编辑入口；原按钮可见后收起，弹窗/移动导航打开时隐藏，兼容安全区与可视视口。

动效焦点为取景框中的光束扫描和画面聚合；排队采用静态待显影状态，运行只展示真实等待时长，不编造上游进度、阶段或 ETA。刚完成的本次作品短暂显影，已有历史不重复播放。循环只使用 CSS transform/opacity，隐藏页面和离屏卡片暂停；减少动态效果保留静态画面和状态文字。

验收：低高度桌面与手机两种布局始终存在可达的生成入口；禁用与自定义尺寸验证一致，单次点击只提交一次；弹窗与侧栏不被遮挡；真实排队/运行/失败/取消/成功状态有明确反馈；普通和减少动态效果录帧，单测、类型、lint、构建及浏览器回归通过。

## 统一图片预览补充（2026-11-17）

用户要求上传图和生成图都可预览。本次覆盖参考图（上传/粘贴/拖入）、已保存结果、未保存结果、历史参考图和素材，不改计费/生成/持久化契约。复用 BlobImage 释放 object URL 和 BaseDialog 的弹窗栈/滚动锁，新增独立本地图片预览组件。素材点击图片改为预览，使用参考图保留为明确按钮。

预览按当前集合浏览，展示完整未裁切图片，支持上一张/下一张与缩略图、适应窗口/原始尺寸、缩放、拖动、滚轮及触摸缩放，下载当前图片；显示实际尺寸和格式，图片加载失败可本地重试。键盘支持 Escape 关闭、方向键切图、加减缩放、Shift+方向键移动放大图片，焦点限制在顶层预览并在关闭时归还。切图重置缩放/拖动；切换账号清空预览。提示词折叠避免挤占手机图片区域。

验收：各入口有可访问的预览操作；预览/切图/缩放/下载不提交生图、不发送图片到服务器；多图导航和错误重试、对象 URL 释放、弹窗叠加和焦点回归通过自动化检查；桌面/手机横竖屏不溢出，完整图片比例正确。既有三个审查遗留保持单独记录。
